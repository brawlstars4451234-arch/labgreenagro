# IoT Smart Greenhouse SCADA Web Dashboard

Современный учебный прототип веб-платформы интеллектуального управления теплицей (Smart Agriculture IoT System).

## 📌 Описание проекта
Данная система предназначена для мониторинга климата, автоматизации полива, вентиляции, освещения и аварийных событий в реальном времени.

## 🚀 Основные возможности
- **Мониторинг климата**: Температура, влажность воздуха, влажность почвы, освещенность, CO2, уровень воды.
- **Управление и Автоматизация**:
  - Режимы `AUTO` / `MANUAL` для каждого сектора.
  - Гистерезис переключения реле.
  - Защитная блокировка полива при низком уровне воды.
- **Smart Analytics**:
  - Расчет коэффициента риска (Risk Score 0-100%).
  - Детекция резких изменений и аномалий.
  - Интеллектуальные рекомендации для оператора.
- **Визуализация**: Интерактивные графики Chart.js.
- **Хранение**: Все настройки и события сохраняются в `localStorage`.

## 🌐 Развертывание
1. Запустите локальный сервер (например, через VS Code Live Server).
2. Для публикации на **GitHub Pages**:
   - Перейдите в Settings репозитория -> Pages.
   - Выберите ветку `main` и папку `/(root)`.
